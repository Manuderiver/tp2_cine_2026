## 📄 Descripción
Este proyecto consiste en el desarrollo de una aplicación web para un cine, donde los usuarios pueden visualizar películas en cartelera, consultar detalles, registrarse, iniciar sesión y ver su perfil.

## 🧩 Funcionalidades principales
- 📌 Página principal con películas en cartelera (implementada con CSS Grid)
- 📌 Página de detalle de película (implementada con Flexbox)
- 📌 Sistema de login y registro
- 📌 Perfil de usuario
- 📌 Página de próximos estrenos

## 📱 Diseño responsive
El sitio se adapta a diferentes tamaños de pantalla utilizando media queries.
